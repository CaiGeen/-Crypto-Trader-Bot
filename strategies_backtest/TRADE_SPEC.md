## A. 数据与指标（同v1）
- ATR=RMA(TR,20)对齐TradingView；KAMA=10/2/30，取前一根收盘值 kama[j−1]（**固定值，非动态**）

## B. 入场条件（v2重构：信号驱动 → 挂单状态机驱动）
- B1.（用户）"收盘>6K极值才做多"在盘中不成立：挂单在基准线确认后即在场内，**价格触及触发线即市价成交，与该K收盘是否突破6K极值无关**
- B2. 挂单生命周期（多头，空头镜像）：
  - **6K突破环境门（2026-08-23用户折中方案）**：收盘突破6K极值 → 环境激活；此后每根K最低价不跌破**前一根K的KAMA值** → 环境维持；某根K最低价跌破前K KAMA → 环境失效、撤单（"跌破KAMA撤单"），等下一次收盘突破重新激活
  - **武装（须环境开启）**：环境内，某K高点H后连续2根不创新高（第2根收盘确认）→ 基准线=H，触发线=H+ATR(H当根)；最少3根K即可确定挂单位置
  - **更新（E2.b）**：挂单等待期间出现高于H的新高点（未及触发线），该高点后连续2K不创新高 → 基准线与触发线更新为新高点（ATR同步取新高点当根）
  - **撤单·收盘破线（E2.c）**：收盘突破6K极值但挂单未触发，其后**连续3根收盘跌破基准线** → 撤单，重新等新基准线【解释点2：中间收盘回到基准线上方则重新计数】
  - **撤单·3ATR区间（E6）**：自基准K起，区间最高价−最低价 > 3×ATR(最新收盘K) → 撤单，等新的<3ATR区间内的新基准线【解释点3：区间从基准K起算】
  - 挂单**无时间有效期**
- B3. 触发判定用4H high/low（与1分钟判定等价，已验证）；成交价=触发线

## C. 三止损规则（G2扩展版）
- C1. **规则①初始止损**：=基准线。买入后第1~3K，盘中跌破按线价成交，R=−1R（止损优先于一切）
- C2. **规则②保护性平仓（扩展）**：**成交当根及第1、2、3K的每次收盘**都检查：收盘 < 基准线+1.5×ATR → 按该收盘价平仓，**注明第几K**（第0K=成交当根）
  - 边界：收盘已穿基准线 → 按基准线价成交记ATR止损（止损优先）
  - 【解释点4：第3K收盘检查通过后进入规则③】
- C3. **规则③成本线时间锁**：买入后第3K收盘仍持仓 → 止损上移至成本线（成交价）；第4K起止损=max/min(KAMA[前K收盘值], 成本线)
- C4. KAMA止损语义（G6澄清）：KAMA取**前一K收盘的固定值**，止损单挂在该固定价格，最新K最低价跌破它 → **按线价成交**。唯一例外：K线开盘时挂线价已高于现价（如成本线刚上移、开盘在成本线下方）→ 按开盘价市价成交（物理上不可能按线价成交）
- C5. 止盈：基准线×1.22（多）/×0.88（空），盘中触及成交，止损优先

## D. 开新仓规则（J4，用户确认）
- D1. **开新仓条件 = 无持仓 或 全部持仓的止损已上移至≥成本线（保本）**——永远只承担一份新风险
- D2. 保护性平仓/止损后无持仓 → **立即可再开新仓**（无空锁）
- D3. 第1~3K内的持仓（止损=基准线<成本线）视为未保护，阻止新成交

## E. 成交当根1分钟消歧（F标注）
- E1. 成交当根用1分钟K线定位成交时刻，判定"先触发还是先破止损线"
- E2. 判定规则同前（成交1m的开盘价位置裁决）
- E3. **成交明细CSV标注"1m消歧"列**：成交当根曾出现低于基准线的价格（需消歧）=是——凭4H肉眼容易看错的单都在此列

## F. 全波段记录（C4/L，新增）
- F1. **全数据CSV记录每一个基准线（波段）**，无论成交与否：`results/全波段明细_订单状态机*.csv`
- F2. 状态列注明结局：成交 / 被新基准线替换 / 3ATR区间撤单 / 收盘破线3根撤单 / 未触发至数据末尾
- F3. 未成交波段附**未成交错过%**（基准形成至撤单期间，顺向行情超出触发线的幅度）——用来量化"策略没赚到的钱"
- F4. 成交波段附完整交易字段（含保护性平仓第几K、1m消歧标记）

## G. 统计口径
- G1. R=(出场价−入场价)/ATR(基准K当根)；初始止损=−1R、成本线=0R
- G2. **波段涨跌幅只记2个值（K4）**：基准线起点 与 6K极值起点（峰值=基准K..出场/撤单K区间极值）——入场后涨跌幅已删除
- G3. MAE（K6说明）：成交K..出场K的最不利幅度（相对入场价）。用途：持仓最大浮亏分布→止损空间是否够、心理压力、不同入场质量对比。可按需删除
