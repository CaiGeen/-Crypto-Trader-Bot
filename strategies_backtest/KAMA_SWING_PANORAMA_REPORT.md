# KAMA 纯市场波段全景报告

- 数据：BTC/USDT 永续 4H，`BTCUSDT_4h.parquet`，15266 根，2019-09-10 → 2026-08-26（KAMA 预热后）
- KAMA：ER=10 / fast=2 / slow=30（TradingView 对齐）；参考值 = 前一根K收盘确认的 KAMA
- ATR：Wilder ATR(20)（项目标准口径），起点价使用突破K当根 ATR
- 起点价：多头 `high[i]+ATR[i]`；空头 `low[i]-ATR[i]`（进入趋势扩张区的门槛，而非成交价）
- 持续K数含起始K与终结K（最小 2）；极值在 `[start, end]` 闭区间上取；终结K与下一波段起始K允许同根

## 六、波段之间关系

- 前波段涨幅 → 本波段涨幅：Spearman ρ = **0.25**（n=4701）
- 前一波段结束后，下一波同方向比例 = 54%（同向中位 -1.15% vs 反向中位 -1.06%）
- 前波段为前 25% 大行情时，本波段 ≥ 全体 P75（-0.41%）的概率 = 27%（基准 25%）
- ρ 拆分：同向重启对 0.25 / 反向切换对 0.26 —— 相关性不来自同K重叠伪影；更可能是波动 regime 共因子（高 ATR 期相邻波段同时放大）。分位数检验 27% vs 基准 25% 才是可用预测力的真实量级

**结构性发现：本定义下「波段间整理时间」不存在。** 终结K收盘几乎必然满足某一方向的起始条件（close ≠ kama 前值），因此 100% 的波段转换都是同K重启，市场被无缝切分为交替的趋势状态段。如需研究整理期，需换口径（例如「距上一个进入扩张区波段极值的K数」或「连续未过扩张区的波段数」）。

## 十、数据直接给出的策略优化线索

1. **KAMA 退出并不早，反而有回吐成本**：等 KAMA 终结确认平均要把峰值让回 1.32%（中位）——扩大收益的方向不是更晚离场，而是终结前的跟踪止损/分批。
2. **第 3K 保本偏早**：活过 3K 的波段此后仍有中位 0.00% 剩余空间（P75 1.26%）；活过 5K 后 P(≥5%) 升至 16%（基准 4%）。生存信息本身就是过滤器：age≥5 再上收紧的保护更划算。
3. **时间即信息**：持续K数与涨幅 Spearman ρ（多/空）= 0.58 / 0.54；21K+ 长波段贡献了分布的右尾，对它们任何提前离场规则都昂贵。
4. **前波段不预测后波段**：ρ = 0.25（多为波动共因子），分位数检验 27% vs 基准 25% 无可用预测力——不应应用「上一波大」做任何下注；且本定义下波段间休整恒为 0（同K重启），无整理期可言。
5. **超额收益集中于头部**：前 10% 波段贡献大部分正涨幅（见第二节），策略的目标函数应是「不漏掉头部」而非「提高平均」。
