## 〇、统一口径策略（用户2026-08-22确认）

| 环节 | 规则 |
|------|------|
| 信号 | 6K极值突破（close[i]超前6根极值）；无回调线不开仓 |
| 入场 | 挂单在触发线=回调线±1×ATR（自信号K开盘生效），价格触及即**市价买入**（成交价=触发线）；6根K未触发作废 |
| ATR | 回调线当根K收盘值（RMA20） |
| 止损① | 初始止损=回调线，盘中触及按线价市价出场（成交当根用**1分钟K线**消解先后顺序） |
| 止损② | 成交当K收盘 < 回调线±1.5×ATR → **保护性平仓**（按收盘价；收盘已穿止损线则按线价，止损优先） |
| 止损③ | 买入后第3K收盘未打损 → 止损上移到**成本线**（=成交价）；此后止损=max/min(KAMA,成本线)，KAMA跟踪接管，跳空穿越按开盘价 |
| 止盈 | 回调线×(1+22%)做多 / ×(1−12%)做空 |
| 波段涨跌幅 | (峰值−回调线)/回调线，峰值=信号K..出场K最高/低（含信号K） |

## 五、规律（本口径下）

### 规律1：峰值R中位1.48R，高ATR折价仍在
全样本峰值R中位1.48R、均值2.45R、P90=4.77R。分档：ATR<1.5%→1.61R、1.5-2%→1.46R、2-3%→1.36R、3-5%→1.22R（≥5%组17段1.38R样本小）。**波段涨跌幅≈(1.2~1.6)×ATR**，且涨跌幅~ATR%相关性升到0.51（截断下限随ATR放大所致）。

### 规律2：左截断取代对数正态
市场原始波段分布是对数正态（参照旧口径：KS p=0.89），本策略成交的波段被"触发线≥1ATR"截断后用对数正态描述已不成立——估算空间应按"下限1ATR+右偏尾部"建模。

### 规律3：保护性平仓是最大的出场出口（69%）
742单死于成交当K收盘<1.5ATR——**三分之二的信号"碰得到触发线、收不出实体强度"**。它们的波段涨跌幅中位2.13%（有峰值但收盘回吐），平均亏损小（-0.2R级）但累计消耗显著。

### 规律4：回调偏移>0仍有优势但减弱
中位差+0.49pp（p<0.0001，CI[0.28,0.83]）——比回调线直接入场口径（+0.80~0.93pp）弱：触发线入场对"入场价"的敏感度更低。

### 规律5：年度漂移保持
2019-2026中位：2.5/2.8/**3.8**/2.8/2.1/2.4/2.0/1.9——2023年后小波段市场结论不变。
